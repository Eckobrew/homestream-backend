# HomeStream Kotlin client

Generated by `npm run contract:kotlin` from `contract/openapi.json`. Requires JDK 21 for the build:

```bash
./gradlew compileKotlin --no-daemon
```

The OkHttp client is suitable for Android. Calls are blocking: invoke them off the main thread. The constructor accepts a server URL and an optional bearer credential. JSON operations return an `ApiResponse<T>` with status, decoded body and raw error bytes. Streaming/artwork operations return an OkHttp `Response` that the caller must close; their bodies are not buffered in memory. Subtitles returned as VTT remain available through raw bytes.

Mixed JSON unions use `JsonElement`; enum constraints are enforced by the server. Unknown response fields are ignored for forward compatibility. Generated models, requests and operation signatures are checked into this repository so client releases can pin them independently.
